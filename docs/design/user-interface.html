画面と制作の導線

会話で依頼し、成果物を横で見る

左に作品と会話、中央にメインチャット、右に横タブ。採否や手作業の記録は会話から行い、成果物・履歴・相談を隣で開く。

設計合意済み 本実装・実機受け入れは後続

主要な契約

項目 決めたこと・受け渡すもの
作品と会話 新規・既存ファイル取り込み・保存状態からの派生。作品別に複数チャットを持つ。
右側タブ 成果物・サイドチャット・制作履歴・保護・作風。＋で開いたタブ内で種類を選ぶ。同じ成果物は既存タブを選択。
編集案の確認 成果物リンクは特定の案・状態・ファイルを固定参照。画像を拡大・移動し、採否・追加修正は会話で伝える。
手作業の記録 本文・添付・セッションの成果物を選択。保存済みblendから通常スクリプトでプレビューを生成し、失敗しても記録を残せる。
サイド相談 保存して開き直せる相談専用チャット。初期文脈を引き継ぎ、制作操作・採否・記録・メインへの依頼の受け渡しはしない。
実行表示 チャットで今行っている作業を停止。停止待ち・状態確認が必要・保留と、明示再開を区別する。
履歴と全体管理 履歴は左から右へ。理由はホバーで確認。作品選択から全履歴の振り返り、設定からバックアップ・実体削除へ。

制約と失敗時の扱い

  • 「記録として送信」はLLMを使わない。相談の通常送信と区別する。
  • タブを閉じても成果物・会話・履歴は削除しない。実体の欠落は欠落と表示する。
  • 画面試作は操作契約の根拠。本実装・性能・ファイル選択のOS連携は未検証。
