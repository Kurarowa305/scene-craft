作品と制作履歴

保存状態をつなぎ、判断の理由を残す

作品は完成した一枚を目指す単位。AI案・手修正・採否の分岐をつなぎ、何を見て判断し、どこから次の制作を始めたかを追跡する。

主要な契約

項目 決めたこと・受け渡すもの
作品・会話・原文 作品の共有情報と複数会話を管理。原文メッセージは順序・発言者・添付・途中や欠落を保持する。
依頼・実行・再実行の記録 目的と予算の単位、AIとWindowsの親子実行、そのやり直しを分ける。Codex thread/turnの対応は接続記録。
ファイル参照・生成物 固定実体とAI等の成果物を区別。人間が取り込んだファイルをAIの生成物と呼ばない。
保存状態・変更記録 固定した構成と依存素材、変更前後と由来。手修正・復元・派生も変更記録でつなぐ。
編集案・採否記録 基準と候補、代替・依存・修正元を保持。判断は実際に確認した状態と範囲を参照する。
現在状態の更新記録 次の制作の出発点をいつ、どの採否・変更で切り替えたかを記録する。
文章記録・振り返りの参照記録 理由・要約・制作意図は訂正履歴付き。分析が当時使った文章・採否・実体を固定する。

制約と失敗時の扱い

  • 15概念を上の7群に整理している。物理的なテーブル分割を表すものではない。
  • 案の完成・候補上の修正だけで現在状態を更新しない。未選択と不採用は別。
  • 復元は直前と復元元を残す新記録。派生は別作品。理由の訂正や実体削除で過去の判断を消さない。
