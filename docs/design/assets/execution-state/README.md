# 依頼の状態遷移図

`execution-lifecycle.html` の「状態遷移の全経路」にあった25行の
遷移前・条件／操作・遷移後を `transitions.json` に保存している。
受付・完了と停止・結果照合・再開の4図に分け、各経路を1回ずつ掲載する。
図をまたぐ同じ状態名は、同じ依頼状態を表す。

Graphvizが生成する静的SVGを使用し、ブラウザで外部スクリプトや描画サービスへ接続しない。
元の経路IDはSVGの矢印グループ、JSON、本文のテキスト表示で対応付けられる。
元の状態名・条件を変更する場合は詳細Markdownの設計と揃え、
図だけでなく本文のテキスト表示も更新する。

## 再生成

Graphviz（`dot`）とPythonを用意して、リポジトリルートから実行する。

```sh
python docs/design/assets/execution-state/build.py
```

`.dot` は生成元のレイアウト定義、`.svg` はブラウザで表示する画像。
生成後は通常幅・狭い幅・印刷で、条件の読みやすさと矢印の対応を確認する。
