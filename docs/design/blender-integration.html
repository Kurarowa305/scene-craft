DESIGN / 08

Blender連携とレンダー出力

編集できる3Dから、13レイヤーへ

WindowsのBlenderをbackground実行し、保存済み入力のコピーをPythonで処理する。Cyclesから16bit RGB・sRGBのPSDを生成し、上限時はPSBへ切り替える。

主要な契約

項目 決めたこと・受け渡すもの
編集可能な制作データ 部品別形状、UV・画像接続、材質ノード、環境設定をblendへ残す。植物の個体取り出しは分布から除外し、再生成で二重化しない。
色と表示 13枚を同じカメラ・フレーム・解像度に揃える。新規作品はAgX・露出0。見た目用の変換とデータ画像の符号化を分け、sRGB ICCを埋め込む。
影とアルファ Shadowsは指定受け面のShadow Catcher。影用コピーと通常Combinedを分ける。Global Alpha Maskは背景として指定した空を除く。
深度とID 深度は近白・遠黒、範囲と元の距離EXRを保持。物体・材質ごとのID色を固定し、名称変更で変えず、削除した色を再利用しない。
生成方式 PhotoshopAPI 0.9.1でレイヤーを作り、psd-tools 1.24.0で名称・merged imageを補修。再読込・画素・ICC検査後に完成として公開。
形式と完成 統合レイヤーだけ初期表示、残り12枚は非表示。上限超過は同条件のPSBへ。必須パスの欠落を空画像や品質低下で隠さない。

13レイヤーの役割

Material IDとObject IDは別レイヤー。成分を重ねて元画像を厳密に再合成する要件は持たない。

項目 決めたこと・受け渡すもの
統合レイヤー Combined。初期表示する画像。
Material ID / Object ID 材質・物体ごとの色分け。個別の白黒マスクは作らない。
Material color Diffuse Color。万能なベース色ではない。
Specular Lighting Glossy Direct × Glossy Color。
Diffuse Lighting Diffuse Direct。材質色を掛けず、影を含む。
Z Depth 距離を指定範囲の白黒へ変換。原値はEXRに保持。
Global Alpha Mask 空を除く物体のAlpha。
Shadows 指定受け面のShadow Catcher。
Refractions TransmissionのDirect＋IndirectにColorを掛ける。
Reflections Glossy Indirect × Glossy Color。
Indirect Lighting Diffuse Indirect。材質色を掛けない。
Ambient Occlusion AO。補助調整用。

制約と失敗時の扱い

  • 保存済みデータだけが対象。GUIの未保存内容を自動取得しない。同じデータを人間とAIが同時編集しない。
  • Shadows未指定なら指定を求める。人間が「対象なし」を明示したときだけ白いShadowsと対象なしの記録を残す。
  • 停止は所有するプロセスを対象にし、編集・保存は安全な境目、レンダーは中断。未完成画像を成果物にしない。
