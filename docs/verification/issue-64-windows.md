# Issue #64 Windows 実機確認

対象は右タブの相談専用サイドチャット。CIの代替Codex、現行Codexの非推論契約確認、Windowsで人間が行う実会話の確認を区別する。

## 起動

1. 起動中なら画面右上の「アプリ終了」で終了する。ブラウザを閉じるだけでは終了しない。
2. デスクトップの `scene-craft` を開く。今回ビルドした `codex/64-side-chat` の画面を起動する。mainへのマージは不要。
3. Windowsの配置は `%LOCALAPPDATA%\scene-craft\Launcher.ps1` と `Test-Local.ps1`。`launcher.json` とファイル保存ルート・ログイン・既存データの設定は維持する。
4. 作品を選択し、左の「＋」で確認用のメインチャットを作る。「Codexとの会話」に「ChatGPT認証済み」が出ることを確認する。必要なら「ChatGPTでログイン」→「専用ログインを開く」→認証後「接続状態を更新」。モデルが利用不可なら実モデル一覧から明示選択する。

独立したデータで確認する場合は、PowerShellで次を実行する。新しい保存先のため専用のChatGPTログインが必要になる。既存アプリが同じポートを使用していれば先に終了する。

```powershell
& "$env:LOCALAPPDATA\scene-craft\Test-Local.ps1" -Config "$env:LOCALAPPDATA\scene-craft\launcher.json"
```

## 結果の記録

`Test-Local.ps1` は `%LOCALAPPDATA%\scene-craft\verification\<run-id>-result.json` に対象コミット・環境・起動スクリプトのhashと手動項目を残す。#64の3項目（parallel consultation / read-only boundary / close, stop and reopen）について `status` を `passed/failed/not_run`、`actual` を観察した結果、`evidence` を画面証跡のファイル参照にする。自動成功を人間確認の成功へ転記しない。

通常の起動設定で確認する場合も、対象commit、Windows・Codex・ブラウザ版、上表の期待/実結果、成功/失敗/未実施、画面証跡を記録する。

現行Codexの非推論確認は[契約確認結果](assets/issue-64-codex-contract.json)を参照。再現はビルド後、WSLで次を実行する（認証・推論なしの専用一時領域を使用）。空threadは保存済みturnがないためcold resumeの検証対象にせず、上表11で確認する。

```sh
node --import tsx scripts/probe-side-chat.ts /path/to/codex /tmp/issue-64-contract.json
```
