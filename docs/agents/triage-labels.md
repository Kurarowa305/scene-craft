# Triage ラベル

| 役割 | 管理先のラベル | 意味 |
| --- | --- | --- |
| needs-triage | needs-triage | メンテナーによる判断が必要 |
| needs-info | needs-info | 報告者からの追加情報を待っている |
| ready-for-agent | ready-for-agent | 仕様が整い、エージェントが着手できる |
| ready-for-human | ready-for-human | 人間による実装が必要 |
| wontfix | wontfix | 対応しない |

スキルが役割を指定した場合は、対応する管理先のラベルを使う。
